# Support

## Getting Help

- **Documentation**: See `docs/` directory and module docstrings (`ansible-doc voipnorm.roomos.roomos_command`)
- **Bug Reports**: [GitHub Issues](https://github.com/voipnorm/ansible-collection-roomos/issues/new?template=bug_report.yml)
- **Feature Requests**: [GitHub Issues](https://github.com/voipnorm/ansible-collection-roomos/issues/new?template=feature_request.yml)
- **Discussions**: [GitHub Discussions](https://github.com/voipnorm/ansible-collection-roomos/discussions)

## Compatibility

- Python >= 3.10
- Ansible >= 2.15
- RoomOS 11.x and 26.x (CE 9.x is not supported)

See [docs/compatibility-matrix.md](docs/compatibility-matrix.md) for details.
